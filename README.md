
cara pakenya:
1. download terus taro di desktop
2. klik kanan file spk_ekskul_fadilah.rar pilih extract here
3. cut folder spk_ekskul_fadilah taro di folder c: xampp htdocs
4. nyalain xampp apache dan MySQL
5. buka localhost/phpmyadmin atau localhost:8080/phpmyadmin 
6. buat database baru spk_ekskul_fadilah
7. pilih menu import
8. pilih file spk_ekskul_fadilah.sql yg ada di folder htdocs spk_ekskul_fadilah
9. klik tombol go / simpan
10. ketik localhost/spk_ekskul_fadilah atau localhost:8080/spk_ekskul_fadilah
